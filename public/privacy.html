1. Zero Data Collection & Zero External Uploads

This extension and web dashboard operate 100% locally inside your browser. We do not operate any backend database, analytics, telemetry, or tracking server, and we never receive, collect, store, sell, or transmit your personal data or AI usage metrics.

2. What Data the Extension Reads & How It Works

  • Visible Quota Percentages Only: On supported AI provider usage pages (claude.ai, chatgpt.com, openai.com, antigravity.google.com, kimi.com, kimi.ai, moonshot.cn), the extension reads only visible quota usage labels and reset countdowns from the page DOM.
  • Never Reads Secrets or Prompts: It never reads cookies, session tokens, passwords, API keys, billing details, or chat conversation history.
  • Direct In-Browser Messaging: Extracted quota text is forwarded directly inside your own browser via chrome.tabs.sendMessage and window.postMessage to your open AI Quota Tracker tab (ai-quota-tracker-ten.vercel.app or optional localhost:3456 companion).
  • Local Browser Storage Only: Quota state is saved solely in your browser's localStorage and chrome.storage.local, which you can wipe anytime using Clear Local Data.

3. Chrome Extension Permissions Justification

  • tabs & activeTab: Used to detect which supported AI provider usage tabs are already open so duplicate tabs are not opened, and to focus or sync active provider tabs.
  • scripting: Used exclusively on allowlisted AI provider domains and the Dashboard domain to read visible quota bars cleanly inside the page.
  • storage: Stores local sync timestamps and temporary quota payloads inside chrome.storage.local across extension service worker wake-ups.
  • alarms: Periodically triggers lightweight in-browser tab checks so quota bars stay up to date.
